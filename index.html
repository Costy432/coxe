FAQ

Common questions

On Forge 1.8.9 or Fabric 1.21.11 take the matching Mod jar — that is the tightest integration. If you switch versions a lot, use Lunar / Feather / Badlion, or play on CraftRise, take the External: one exe covers 1.20 → 1.21.11 with no loader.

1.8.9: Forge for 1.8.9 (11.15.1.2318 recommended) and Java 8+ — coxe-mod-1.8.9.jar. 1.21.11: Fabric Loader, Fabric API and Java 21+ — coxe-mod.jar.

Yes — the External is tuned for CraftRise. Run coxe-external.exe, leave it open, join CraftRise, then press your GUI key. Nothing in your launcher or game folder changes.

Modules, their slider values, the menu key and the whole HUD layout are packed into one code that looks like CX2.… with a CRC32 tail. The same code is read by this page, the Config Studio and native Configs → Paste. An 8-digit checksum catches accidental edits, and nothing leaves your browser.

The External is Windows 10/11 only. On macOS and Linux use the Mod — Forge 1.8.9 or Fabric 1.21.11, both have the full module set.

It appends padding so the downloaded file lands inside the MB range you set. It never shrinks a file, and it is off by default because some launchers dislike extra bytes on a jar.
