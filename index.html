Why Coxe

Built for the way you actually play

56 modules behind one ClickGUI, two loaders, and a config you can move between machines as a single code. Nothing in the client touches your framerate or your game files.

No FPS tax

Render hooks are batched and every module is off until you switch it on — the client stays out of your frame time. 56 modules, one toggle each.

Two loaders, one client

Fabric 1.21.11 and Forge 1.8.9 jars run the identical module set — same GUI key, same settings, same config codes.

External for CraftRise

One exe covers 1.20 → 1.21.11 with no loader at all, tuned for CraftRise and the usual launchers. Nothing in your game folder changes.

HUD you place yourself

Ten overlay elements, drag them anywhere, then fine-tune scale, phase and colour — and carry the whole layout out as one code.

Config codes, not config files

Every module and every field packs into a CX2 string. Paste it, diff it, share it — the Config Studio handles all 139 fields.

Nothing left behind

Uninstall is a file delete. No services, no background updater, no telemetry — the jar or the exe is the whole thing.

FAQ

Common questions

On Forge 1.8.9 or Fabric 1.21.11 take the matching Internal jar — that is the tightest integration, and the only way to get the render-hook modules. If jars are a hassle, coxe-internal.exe loads the same client for you. If you switch versions a lot, use Lunar / Feather / Badlion, or play on CraftRise, take the External: one exe covers 1.20 → 1.21.11 with no loader.

1.8.9: Forge for 1.8.9 (11.15.1.2318 recommended) and Java 8+ — coxe-mod-1.8.9.jar. 1.21.11: Fabric Loader, Fabric API and Java 21+ — coxe-mod.jar. Nothing to install for coxe-internal.exe or coxe-external.exe; both are Windows 10/11 and start with a double click.

Yes — the External is tuned for CraftRise. Run coxe-external.exe, leave it open, join CraftRise, then press your GUI key. Nothing in your launcher or game folder changes.

Modules, their slider values, the menu key and the whole HUD layout are packed into one code that looks like CX2.… with a CRC32 tail. The same code is read by this page, the Config Studio and native Configs → Paste. An 8-digit checksum catches accidental edits, and nothing leaves your browser.

The External and the Internal loader are Windows 10/11 only. On macOS and Linux use the Internal jars — Forge 1.8.9 or Fabric 1.21.11, both have the full module set.

It appends padding so the downloaded file lands inside the MB range you set. It never shrinks a file, and it is off by default because some launchers dislike extra bytes on a jar.
